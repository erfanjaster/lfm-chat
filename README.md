# 🧠 LFM Memory Chat

یک رابط چت وب زیبا (Gradio) برای مدل لوکال **LFM2.5-1.2B-Instruct** (نسخه
roleplay-tuned، فایل GGUF با کوانت Q4_K_M) با **سیستم حافظه بلندمدت مهندسی‌شده** —
بهینه‌شده برای لپ‌تاپ‌های کم‌رم مثل **HP EliteBook 850 G4 (i5 نسل ۷، ۸ گیگ RAM)**.

> ایده اصلی: یک بار چیزی به مدل یاد بده (مثلاً یک قانون کدنویسی پایتون)،
> و دفعه بعد که درباره همان موضوع سؤال کرد، مدل **خودکار** از آن حافظه استفاده کند.

---

## ✨ قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| 🧠 **حافظه بلندمدت هوشمند** | خاطرات در SQLite ذخیره می‌شوند و بین اجراها باقی می‌مانند |
| 🔍 **بازیابی هیبریدی BM25** | امتیاز = `۰٫۷۲×ارتباط + ۰٫۱۶×اهمیت + ۰٫۱۲×تازگی` + بوست موضوعی (سوال پایتون → خاطرات پایتون بالا می‌آیند) |
| 💪 **تقویت با استفاده** | هر خاطره‌ای که استفاده شود `hits` و `importance` می‌گیرد — مثل تکرار فاصله‌دار (Spaced Repetition) خاطرات مفید بالا می‌مانند |
| ⚡ **استخراج خودکار پس‌زمینه** | بعد از هر پاسخ، یک ترد جدا از همان مدل ۱٫۲B نکات/درس‌های مهم مکالمه را استخراج می‌کند — بدون مدل امبدینگ، بدون رم اضافی |
| 💾 **فرمان فوری `remember ...`** | هر پیام با "remember" شروع شود فوراً ذخیره می‌شود (بدون مصرف CPU برای LLM) |
| 🗜 **خلاصه‌سازی غلتان** | تاریخچه قدیمی به یک خلاصه فشرده تبدیل می‌شود؛ مکالمه بی‌نهایت طولانی با پرامپت محدود |
| ♻️ **ضدتکرار (Dedupe)** | ذخیره خاطره تکراری با Jaccard روی ساقه کلمات شناسایی و ادغام می‌شود |
| 🎭 **قالب دقیق ChatML** | پرامپت دقیقاً طبق قالب رسمی LFM2.5 ساخته می‌شود |
| 📊 **پنل شفاف** | کنار هر پاسخ می‌بینید **کدام خاطرات با چه امتیازی** تزریق شده‌اند |
| 🐢 **سبک روی رم** | کل مصرف: ~۱٫۵–۲٫۵ گیگ (مدل ~۰٫۸ گیگ + Gradio) — هیچ مدل دومِ امبدینگی در کار نیست |

## 📦 نصب (Arch Linux — مرحله به مرحله)

### ۱) پیش‌نیازها
```bash
sudo pacman -S --needed python git
```
پایتون ۳٫۱۰ تا ۳٫۱۳ توصیه می‌شود (پایتون خود Arch معمولاً مشکلی ندارد).

### ۲) فایل مدل
فایل `LFM-2.5-1.2b-Instruct-roleplay-tuned-v2.Q4_K_M.gguf` را داخل پوشه
`models/` همین پروژه بگذار (یا مسیرش را با متغیر محیطی `LFM_MODEL_PATH`
یا در `config.py` تنظیم کن).

### ۳) اجرا — تمام!
```bash
./run.sh
```
اسکریپت به‌صورت خودکار:
- یک محیط مجازی `.venv` می‌سازد (چون pip سیستم Arch به‌خاطر PEP 668 اجازه
  نصب مستقیم پکیج نمی‌دهد)،
- `gradio` و `llama-cpp-python` را نصب می‌کند (فقط بار اول)،
- برنامه را اجرا و مرورگر را روی `http://127.0.0.1:7860` باز می‌کند.

اجرای دستی (بعد از اولین بار):
```bash
source .venv/bin/activate
python app.py
```

**پیش‌نمایش UI بدون مدل:** `python app.py --mock`

> ⚙️ **نصب llama-cpp-python چطور کار می‌کند؟** PyPI برای لینوکس فقط سورس دارد
> (نیاز به کامپایلر)، ولی `run.sh` به‌صورت خودکار **wheel آماده CPU** را از
> ایندکس رسمی پروژه می‌گیرد — نصب چند ثانیه، بدون base-devel:
> ```bash
> pip install llama-cpp-python --only-binary=llama-cpp-python \
>     --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
> ```
> اگر آن ایندکس در دسترس نبود و نصب به کامپایل افتاد:
> ```bash
> sudo pacman -S --needed base-devel cmake
> source .venv/bin/activate
> pip install llama-cpp-python --no-cache-dir
> ```
> CPU شما (i5-7300U) از AVX2 پشتیبانی می‌کند، پس بیلد پیش‌فرض CPU optimal است.
> نیازی به GPU/CUDA نیست (Intel HD 620 پشتیبانی نمی‌شود).
>
> 💡 اگر پایتون Arch بیش از حد جدید بود و وابستگی‌ها اذیت کردند، ساده‌ترین راه
> استفاده از `uv` است:
> ```bash
> sudo pacman -S uv
> uv venv --python 3.12 && source .venv/bin/activate
> uv pip install -r requirements.txt
> python app.py
> ```

## 🚀 استفاده

### یاد دادن حافظه — دو راه

**راه ۱ — داخل چت (فوری):**
```
remember that in my Python code I always use pathlib instead of os.path
```
پیام با الگوهایی مثل `remember` / `note` / `don't forget` شروع شود → فوراً
ذخیره و پین می‌شود و مدل تأییدیه می‌دهد (بدون حتی یک فراخوانی LLM).

**راه ۲ — پنل کناری «💾 Teach a memory»:**
متن خاطره را بنویس، نوع را انتخاب کن:
- `lesson` — دانش/قانون/الگوی کد که به مدل یاد می‌دهی
- `profile` — اطلاعات شخصی و ترجیحات (اسم، سلیقه، ...)

### مثال سناریوی مورد نظر شما
1. امروز در چت می‌نویسی:
   `remember: when writing python for me, always add type hints and use f-strings`
2. فردا برنامه را اجرا می‌کنی و می‌پرسی:
   `write me a python function that renames files in a folder`
3. موتور BM25 با کلمه "python" آن خاطره را پیدا می‌کند (تگ `python` هم دو
   برابر وزن می‌گیرد)، آن را در system prompt تزریق می‌کند، و مدل کد را
   **با type hints و f-string** می‌نویسد — و در پنل «Memories used this turn»
   دقیقاً می‌بینی کدام خاطره با چه امتیازی استفاده شده.

### مدیریت خاطرات
- **جستجو**: کادر «Search memories» از همان BM25 استفاده می‌کند.
- **پین 📌**: روی یک ردیف جدول کلیک کن → `Pin row` → آن خاطره **همیشه** (فارغ از
  سوال) به پرامپت اضافه می‌شود.
- **حذف 🗑**: انتخاب ردیف → `Delete row`.
- **New chat**: مکالمه جدید، حافظه بلندمدت دست‌نخورده باقی می‌ماند.
- **Reset everything**: پاک کردن کامل (خاطرات + تاریخچه).

## ⚙️ معماری حافظه (خلاصه مهندسی)

```
 پیام کاربر
     │
     ├─► «remember ...»؟ ──بله──► ذخیره فوری در SQLite (importance=0.75, pinned)
     │
     ├─► بازیابی: BM25(سوال) + بوست نوع (python/code → lesson)
     │        امتیاز نهایی = 0.72·BM25 + 0.16·importance + 0.12·recency + 0.02·hits
     │        + همیشه: خلاصه غلتان + حداکثر ۳ خاطره پین‌شده
     │
     ├─► ساخت پرامپت ChatML:
     │        system (شخصیت + خلاصه + خاطرات) + ۸ پیام اخیر خام
     │        برآورد توکن: اگر از ۸۲٪ پنجره رد شد، قدیمی‌ترها حذف می‌شوند
     │
     ├─► تولید پاسخ (streaming) ──► نمایش در UI + ثبت در SQLite
     │
     └─► پس‌زمینه (ترد جدا، بدون بلاک‌کردن چت):
              ۱. استخراج: همان مدل → حداکثر ۲ خاطره (profile/lesson)
                 با ضدتکرار Jaccard ≥ ۰٫۷۲
              ۲. اگر بافر تاریخچه پر شد → خلاصه‌سازی غلتان (≤۱۵۰ کلمه)
```

**چرا BM25 به‌جای مدل امبدینگ؟** روی ۸ گیگ رم با CPU دو هسته‌ای، یک مدل
امبدینگ جدا ~۰٫۵–۱ گیگ رم و latency اضافه می‌خواهد. BM25 خالص پایتون
(با stemming سبک و تگ‌های دو-وزنی) برای مقیاس چند هزار خاطره **زیر ۱
میلی‌ثانیه** و **صفر رم اضافی** است، و بوست‌های موضوعی/اهمیت/تازگی همان
«هوشمندی» مورد نیاز را تأمین می‌کنند.

## 🎛 تنظیمات پرفورمنس (config.py)

مقادیر پیش‌فرض برای i5-7300U (۲ هسته/۴ ترد، ۸ گیگ) تنظیم شده‌اند:

| پارامتر | پیش‌فرض | کی تغییرش بده |
|---|---|---|
| `N_THREADS` | `4` | اگر لپ‌تاپ داغ می‌کند یا کندتر شد → `2` |
| `N_CTX` | `4096` | رم آزاد داشتی → `6144` (رم بیشتر ≈ +۳۰۰MB) |
| `MAX_TOKENS` | `512` | پاسخ‌های کوتاه‌تر/سریع‌تر → `320` |
| `TEMPERATURE` | `0.7` | پاسخ خلاقانه‌تر (رول‌پلی) → `0.9`؛ دقیق‌تر → `0.3` |
| `RECENT_WINDOW` | `8` | مکالمه طولانی‌ترِ خام → رم/پرامپت بیشتر |
| `TOP_K_MEMORIES` | `5` | خاطرات بیشتر در هر پرامپت |

**انتظار سرعت روی این لپ‌تاپ:** ~۸–۱۵ توکن بر ثانیه برای مدل ۱٫۲B با
AVX2 — برای چت کاملاً روان است.

## ❓ سؤالات متداول

**آیا حافظه بعد از بستن برنامه می‌ماند؟**
بله — همه‌چیز در `data/memory.db` است. حتی تاریخچه چت هم برمی‌گردد.

**چطور مطمئن شوم حافظه کار می‌کند؟**
پنل «Memories used this turn» زیر چت، بعد از هر پیام نشان می‌دهد کدام
خاطرات با چه امتیازی به پرامپت تزریق شده‌اند.

**مدل پاسخ نمی‌دهد / خطای Engine error؟**
مسیر GGUF را در `config.py` چک کن. نسخه llama-cpp-python باید جدید باشد
(پشتیبانی LFM2 از `0.3.x` به بعد).

**می‌خواهم رم کمتر مصرف شود؟**
`N_CTX=3072` و `N_BATCH=64` بگذار؛ مرورگرهای سنگین را ببند. کل مصرف برنامه
به ~۱٫۵ گیگ می‌رسد.
